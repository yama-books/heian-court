# GAME DESIGN — 一人の宮廷人生とNPC箱庭
更新: 2026-11-04 JST／状態: 概念設計。数値・確率は未確定、コード未実装

## 1. 最初の立場
プレイヤーが出自による人生の違いを体験できるよう、次の3入口を用意する構想。

| 入口 | 挙動 | 想定 |
| --- | --- | --- |
| 運命に任せる | 性別・出自・家格・初期人脈などを史実で成立する候補から抽選 | 初回の推奨 |
| 生き方から選ぶ | 宮中政治／宮仕え／地方財政／学芸／陰陽道など大まかな希望を指定し、具体的な立場は抽選 | 選択と偶然の両立 |
| 立場を指定する | 時代と条件に一致する出自・地位を選ぶ。高位は特別シナリオとして独立検討 | 学習・研究向け |

性別の指定は「男性／女性／おまかせ」を候補とするが、**同一官職リストから抽選しない**。女性の女官・女房・后妃・皇族に関する経路は制度と史料を調査して個別に構築する。「陰陽師」は自由な魔法職ではなく、陰陽道の知識・家系・宮廷での職務が制約となる。

初期例（仮分類）：摂関家の子弟／中級官人の子弟／地方官の子弟／上流貴族の娘／宮仕えする女性／陰陽道専門家の家／学者の家。**初期抽選重みや希少性は未設定**。

## 2. 世界と進行
- 初期舞台案: 西暦1000年前後の一条朝。史実登場人物の主要な年表は固定し、架空NPCとプレイヤーの人生を可変にする「史実準拠」モードを先行。
- 1ターン＝1季節、1年＝4ターンを暫定案とする。実際の生活・宮中行事・年中行事との整合を検証して調整する。
- ターンの骨格: (a) 宮中情勢と身辺の変化 (b) 職務・社交・家政・学芸等の選択 (c) NPCの自律行動 (d) 事件と関係変化 (e) 年譜への追記。
- NPCは各ターンに欲求・役職・関係・史実イベントを参照して行動。ただし主要な実在人物の死没・任官・婚姻など確定史実を「気分」で変更しない。
- 史実にない場面は「創作イベント」と明示。無関係の実在人物に史料のない犯罪や病因・加害を断定させない。

## 3. 公的地位と影響力
- `court_rank`（位階）、`office`（官職）、`house_status`（家格）、`access`（天皇等への接近）、`patronage`（後見）、`resources`（財力）、`reputation`（評判）を別々に扱う。
- 官位を経験値だけで昇格させない。任官の空席、血筋、推薦、時代の制度、政争が効く。
- 天皇、摂政、関白、内覧、太政大臣・左右大臣、納言・参議、蔵人等の権限を同じ直線順位にしない。母后・后妃・女院・有力な家の当主などの非公式な影響力も関係グラフで表す。
- 宮中職務は称号だけでなく、文書・奏上・儀礼・人事への関与などの行動に結び付ける。職務の範囲は出典確認後に確定する。

## 4. 関係グラフ
関係の種類: 親子、兄弟姉妹、婚姻、后妃、後見、推薦、同僚、対立、交流、師弟、奉仕先。史実の固定辺と、ゲーム中に生成される可変辺を分離する。

一人の相手を「好感度1本」で処理しない。信頼・義理・競争・怨恨・利害・親密さは並存可能。公開人物列伝では関係の強さを断定的に数字表示せず、イベントと人脈の変遷で見せる。

## 5. 人生と結末
- 成功：官職、婚姻、家の存続、財政、人に与えた影響、学芸、名声、信念に沿った生活。
- 困難：病気、失脚、離別、争い、物怪とされた出来事、没落、死亡。恣意的な即死ガチャは避ける。
- 死亡や退官は終局となる一方、人物列伝として残す。子孫の継承プレイは後期拡張。
- 初回の目標は数年の来歴を成立させること。全ての人生を「関白への出世」で採点しない。

## 6. 物怪・信仰・文学
`史実イベント`と`文学由来の演出`を別フラグにする。病気や不幸が起きると、宮中では占術・祈祷・噂が選択肢として現れうる。ただし病因を超自然現象として確定したり、史料のない呪詛を実在人物に帰したりしない。『源氏物語』の六条御息所等は文学世界の参照であり、西暦1000年の史実人物一覧にそのまま追加しない。

## 7. 非同期の他プレイヤー
ローカル人生から生成される公開用の「列伝」を読む。似た出自／同じ後見／失脚からの再起等の切り口で比較できるが、世界一・最強・成績順のランキングは設けない。定型の文と集計による世界情勢は[非同期設計](ASYNC_SOCIAL.md)を参照。

## 8. 確認すべきゲーム性
- 4ターンで「行動と結果のつながり」が実感できるか。
- 高位・中位・女性の宮仕えなどで遊びが単調化しないか。
- NPCの変化をプレイヤーが物語として理解できるか。
- 選択が無関係な史実を破壊せず、なお展開が異なるか。
- 失脚・死亡も意味ある列伝になるか。
